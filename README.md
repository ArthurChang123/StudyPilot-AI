# StudyPilot AI

An AI-powered study assistant built with Python and Streamlit.

## Features

- Generate practice questions from study notes
- Automatically grade answers
- Track quiz history and mistakes
- Schedule spaced repetition
- Track consecutive correct answers
- Review mastered and unmastered questions

## Tech Stack

- Python
- Streamlit
- SQLite

## Run Locally

1. Clone this repository.
2. Create a Python virtual environment.
3. Install dependencies:

   pip install -r requirements.txt

4. Run the application:

   streamlit run app.py

## Current Status

Early development. Question generation currently uses rule-based
Python logic; AI model integration is planned for a future version.
